# Archive

should be read as instructions or cited as the state of the code.

| | Was |
|---|---|
| `PROGRESS.md` | the running working notes, 2026-09-09 to 2026-09-14 |

The design records here still explain *why* a decision was taken, and a
few adjudication notes in `packages/content/scripts/missing-shapes.ts` quote
them by name; that is the one live reference into this directory, and it is
a citation of provenance, not of policy. The current architecture is
`CLAUDE.md` and `docs/design/`; the current state is `STATUS.md`.
